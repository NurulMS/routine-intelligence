# Data Provenance

Routine Intelligence V1 is a personal portfolio project.

- Training exercise names and schedule structure were transcribed from the owner's supplied MuscleWiki workout exports.
- Care routine entries are personal routine information supplied by the owner.
- Study content in V1 is generic/personal planning content.
- No employer, SAP, customer, sales, confidential or proprietary company data is included.
- V1 stores check-in state only in the user's own browser via localStorage.

Before publishing a fork, review all personal data and replace it with synthetic/demo data if desired.
